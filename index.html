System Architecture

Engineered with Zero Third-Party Dependencies

01 / HARVEST & RELAY

Project-Scoped Session Harvesting

Automatically detects and parses active transcripts strictly scoped to the current working directory across Claude Code, Codex, Gemini CLI, Cursor (SQLite WAL backup), Antigravity IDE, Aider, OpenCode, and Goose.

02 / 4-STAGE CONTEXT DIET

Deterministic Skeletonization & MCP Rehydration

Preserves TypeScript/Rust/Go/Python type contracts and signatures 100% intact while collapsing function bodies >= 12 lines into { /* ... */ } and indexing full bodies in .vicem/ledger.json for on-demand vicem_rehydrate calls.

03 / SAFETY & MINIMAL TCB

3-Tier Secret Redaction & Write Guards

Masks provider keys, PEM blocks, and high-entropy assignments locally before any handoff. Built-in SkeletonWriteGuard and SecretCommitGuard prevent placeholder corruption in source files.
